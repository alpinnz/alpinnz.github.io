Tentang Saya

Saya Alfin, Senior Frontend Developer berbasis di Malang dan lulusan Ilmu Komputer Institut Teknologi dan Bisnis ASIA. Pengalaman saya mencakup antarmuka web, aplikasi mobile, dan integrasi API, dengan fokus saat ini pada pengembangan produk frontend.

Sebagai Senior Frontend Developer di PT Ada Ide Langsung Jalan, saya mengembangkan produk Smartlink, termasuk Smartlink Kasir dan Smartlink Owner. Saya juga berkontribusi pada Groapp Access dan Groapp Accounting. Bersama tim produk dan developer lain, saya menerjemahkan kebutuhan menjadi antarmuka responsif, integrasi API yang andal, dan komponen yang dapat digunakan kembali.

Dari Januari 2022 hingga Juli 2026, saya memimpin tim frontend: merencanakan pekerjaan, membimbing developer, meninjau kode, dan menetapkan standar teknis. Di luar pekerjaan produk, saya menerbitkan alat pengembangan untuk lokalisasi, pengujian UI, dan validasi formulir, serta melakukan riset teknis berdasarkan tantangan yang saya temui.
